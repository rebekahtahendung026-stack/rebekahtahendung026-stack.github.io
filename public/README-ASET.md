# Aset yang perlu kamu siapkan

Letakkan file di folder `public/`:

| File | Keterangan |
|---|---|
| `public/foto.jpg` | Foto profesional, rasio 1:1, minimal 800×800 px. Jika tidak ada, website otomatis menampilkan monogram "RT". |
| `public/cv.pdf` | CV dalam format PDF. Saat ini berisi **draft** — ganti dengan CV aslimu. |

Catatan:

- Jangan hapus `public/cv.pdf` kecuali kamu langsung menggantinya, karena tombol "Unduh CV" mengarah ke file itu.
- Kompres foto sebelum diunggah (target < 200 KB) agar skor Lighthouse tetap tinggi.
